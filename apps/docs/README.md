# ChainPay Documentation

This is the developer documentation portal for **ChainPay**, built with Next.js. It contains integration guides, API specs, SDK descriptions, and step-by-step instructions for merchants to set up and query payment configurations.

---

## 🛠 Getting Started

### Run Development Server

To run only the docs server locally on port `3001`:

```sh
pnpm --filter docs dev
```

### Build for Production

To build the documentation portal:

```sh
pnpm --filter docs build
```

---

## 📖 Contents Overview

- **API Guides**: Learn how to authenticate, create payments, and handle callbacks/webhook responses.
- **Web Integration**: Walkthroughs for using ChainPay widgets or SDKs directly within React/Next.js and other frameworks.
- **Customization Guide**: Instructions on styling options, redirect behavior, and transaction status polling.
